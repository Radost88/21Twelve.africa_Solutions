Flame Knockdown

Tremendously strong flame knockdown and cooling effect. Reduces lithium-ion fire temperature from 400 degrees-plus to below 60 degrees immediately.

Thermal Propagation Barrier

Acts as a fireblock between adjacent cells in a battery pack, preventing thermal propagation from spreading to neighbouring cells.

Reignition Prevention

Unique formula insulates the cells and prevents reignition. Stops thermal runaway by extracting heat and halting the underlying chemical reaction.

Superior Encapsulation

Covers and affixes directly to the battery surface, forming a protective layer that removes heat and separates oxygen and fuel from each other.

Minimal Runoff

Less than 10 percent runoff of the amount sprayed on a flat surface, reducing secondary water damage compared to conventional suppression methods.

Environmentally Safe

Non-toxic and fully biodegradable composition. Safe for enclosed environments including server rooms, data centres and commercial buildings.

Backend Integration Requirements — Developer Notes

eCommerce Backend
Recommended: Node.js (Express) or Python (Django/FastAPI) REST API with a PostgreSQL database for product catalogue, inventory, orders, and customer accounts. Integrate a South African payment gateway such as PayFast, Peach Payments, or Ozow for secure ZAR transactions. Cart state should be managed server-side with JWT authentication for logged-in users.
Contact Form
Implement a server-side form handler (Node/Express or PHP/Laravel) with server-side validation, CSRF protection, and reCAPTCHA v3 for spam prevention. Send confirmation emails via SendGrid or AWS SES. Store submissions in a database and route to a CRM such as HubSpot or Pipedrive via webhook.
Authentication and Accounts
Use OAuth 2.0 / JWT for customer authentication. Build a customer portal using Next.js or Nuxt.js (SSR/SSG) for order history, licence management, and platform access. AWS Cognito or Auth0 handle enterprise SSO requirements cleanly.
IoT Platform Integration
Connect the Argon X backend via WebSocket or MQTT for real-time event streaming to the dashboard. Use TimescaleDB or InfluxDB for time-series telemetry storage. An API gateway (AWS API Gateway or Kong) manages rate-limiting and authentication for device-side calls. Deploy with Docker on AWS ECS or Kubernetes for scalability.
Content Management
Use a headless CMS such as Sanity, Contentful, or Strapi to allow the 21Twelve team to update product descriptions, pricing, and landing pages without developer involvement. Pair with a Next.js frontend using ISR (Incremental Static Regeneration) for performance.
Infrastructure and Compliance
Host on AWS (Cape Town region af-south-1) for POPIA compliance and data residency. Use Cloudflare for CDN, DDoS protection, and SSL termination. Automated backups to S3, monitoring via Datadog or New Relic, and CI/CD through GitHub Actions or GitLab CI. Security scanning with Snyk and OWASP ZAP for vulnerability assessments.
